# موقع مشروع المثبت في المستودع الموحد

يقع مشروع مثبت Acelle Mail ضمن `AcelleMail-Windows-Installer/` في مستودع OFUQ الموحد.

تُحفظ هنا ملفات المشروع والتوثيق وسكربتات البناء العامة. لا يعني وجود هذا المجلد أن ملف EXE النهائي قد بُني أو اختُبر؛ يجب تسجيل نتيجة بناء Windows واختبار التثبيت والتشغيل بشكل منفصل.
