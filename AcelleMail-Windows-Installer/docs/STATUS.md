# حالة مشروع مثبت Acelle Mail

الحالة: غير مكتمل، ولا يوجد مثبت EXE موثّق على أنه ناجح حتى الآن.

المتبقي:
1. إضافة ملفات سكربتات البناء والتجهيز إلى هذا المجلد.
2. توفير حزمة التطبيق المرخصة عبر مسار خاص وآمن، وليس عبر هذا المستودع العام.
3. مراجعة توافق PHP وMariaDB مع إصدار Acelle.
4. تشغيل بناء Windows x64 والتحقق من ملفات الناتج.
5. اختبار تثبيت نظيف على Windows 10/11، ثم اختبار قاعدة البيانات والتشغيل والإيقاف والسجلات.

لا تعتبر المشروع جاهزًا للتوزيع قبل اجتياز جميع الاختبارات.
