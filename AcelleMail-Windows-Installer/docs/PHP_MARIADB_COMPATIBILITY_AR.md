# تقرير توافق PHP وMariaDB — Acelle Mail 3.0.21

## خط الأساس المرشح
- PHP 7.4.33 x64 NTS (VC15).
- MariaDB 10.11.19 x64 portable.

هذه إصدارات مرشحة للاختبار وليست اعتماد توافق نهائيًا. PHP 7.4 انتهى دعمه الرسمي؛ لا تعرض التطبيق على الإنترنت اعتمادًا على هذا الاختيار، واجعل التشغيل المحلي مقيدًا بـ 127.0.0.1.

## ما يجب التحقق منه قبل البناء
1. التحقق من SHA-256 الرسمي لحزمة PHP قبل فكها. لا تعتمد على قيمة تجزئة غير متحقق منها.
2. التحقق من SHA-256 الرسمي لحزمة MariaDB ووجود mysqld.exe وعميل SQL وأداة تهيئة قاعدة البيانات.
3. اختبار php -v وphp -m ثم تشغيل التطبيق مع قاعدة بيانات فعلية.
4. اختبار تثبيت نظيف على Windows 10/11 x64.
5. توثيق نتائج التشغيل والإيقاف وحفظ البيانات والسجلات.

## الحالة الحالية
لا توجد ملفات Runtime فعلية مضمنة في مستودع المصدر، ولم يُبنَ EXE ولم يُختبر تثبيت Windows نظيف. راجع TEST_CHECKLIST_AR.md.
