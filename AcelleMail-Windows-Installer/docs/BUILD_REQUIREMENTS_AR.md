# متطلبات بناء مثبت Windows فعلي

## الهدف
تشغيل Acelle Mail 3.0.21 محليًا على Windows 10/11 x64 دون اشتراط Docker لدى المستخدم.

## المتطلبات
- ملف التطبيق داخل payload باسم AcelleMail_3.0.21_ReviewBuild_v4_EasyInstaller.zip.
- PHP for Windows x64 NTS متوافق مع Laravel 5.4 ومكتبات التطبيق، بعد التحقق من checksum الرسمي.
- MariaDB x64 portable مع التحقق من checksum الرسمي ووجود خادم قاعدة البيانات وعميل SQL وأداة التهيئة.
- Inno Setup 6 على جهاز البناء.
- مراجعة تراخيص التطبيق ومكونات PHP وMariaDB وحقوق إعادة التوزيع.

## الحالة
المشروع ليس مثبتًا نهائيًا. لا تنشر EXE قبل نجاح البناء واختبار تثبيت نظيف وتشغيل وإيقاف وحفظ البيانات على Windows 10/11.
