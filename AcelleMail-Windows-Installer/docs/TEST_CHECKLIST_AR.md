# قائمة اختبار قبول نسخة Windows

- [ ] التحقق من مصدر وتجزئة SHA-256 لكل runtime.
- [ ] التحقق من توافق PHP مع Laravel 5.4 والتبعيات.
- [ ] وجود php.exe وphp.ini والامتدادات المطلوبة.
- [ ] وجود خادم قاعدة البيانات وعميلها وأداة التهيئة.
- [ ] نجاح بناء EXE عبر Inno Setup 6.
- [ ] تثبيت نظيف على Windows 10 x64.
- [ ] تثبيت نظيف على Windows 11 x64.
- [ ] فتح التطبيق محليًا على 127.0.0.1 فقط.
- [ ] التحقق من حفظ البيانات بعد إيقاف التطبيق وإعادة تشغيل Windows.
- [ ] اختبار الإيقاف والتشغيل وتعارض المنافذ والسجلات.
- [ ] اختبار النسخ الاحتياطي والاستعادة وإلغاء التثبيت.
- [ ] توثيق SHA-256 وسجل البناء ونتيجة كل اختبار.

لا تعتبر النسخة جاهزة حتى تكتمل الاختبارات الفعلية على Windows.
