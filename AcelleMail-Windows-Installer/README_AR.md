# مشروع بناء مثبت Acelle Mail لنظام Windows

هذا المجلد مخصص لملفات مشروع المثبّت المحلي لـ Acelle Mail 3.0.21.

## هيكل المشروع
- `AcelleMail-Setup.iss` — تعريف Inno Setup للمثبت.
- `scripts/` — سكربتات تجهيز Runtime وبناء المثبت.
- `src/` — مشغّل التطبيق وسكربت الإيقاف.
- `docs/` — متطلبات البناء، التوافق، وقائمة الاختبارات.
- `.github/workflows/` — سير عمل GitHub Actions لبناء نسخة Windows.
- `payload/` — حزمة التطبيق المصدرية؛ أضفها فقط إذا كان لديك حق إعادة توزيعها، وانتبه إلى حدود حجم GitHub.

## حالة البناء
وجود ملفات المشروع لا يعني أن ملف EXE النهائي جاهز. يجب تشغيل البناء على Windows والتحقق من نجاح تثبيت نظيف قبل إعلان اكتماله.

راجع `docs/STATUS.md` و`docs/TEST_CHECKLIST_AR.md` قبل إصدار النسخة.
