# Acelle Mail Windows Installer (OFUQ)

هذا المجلد مخصص لملفات إعداد وبناء مثبت Windows الخاص بمشروع Acelle Mail، داخل مستودع الأرشيف الموحد.

## حالة المشروع
- هذا المجلد لا يحتوي على ملف EXE نهائي.
- لا تُرفع حزمة Acelle التجارية إلى هذا المستودع العام.
- ملفات البناء تحتاج إلى نسخة التطبيق المرخصة، وبيئة تشغيل متوافقة، ثم اختبار فعلي على Windows.
- PHP 7.4 منتهي الدعم؛ لا يُستخدم المشروع كخدمة مكشوفة على الإنترنت قبل مراجعة التوافق والأمان.

## تنظيم المجلد
- `docs/`: التوثيق وقائمة الاختبار.
- `scripts/`: سكربتات تجهيز بيئة Windows وبناء المثبت.
- `src/`: مشغل التطبيق وأداة الإيقاف.
- `payload/`: **مستبعد من المستودع العام**؛ لا تضع فيه نسخة Acelle التجارية هنا.
- `.github/workflows/`: سير عمل البناء.

## قبل البناء
تأكد من توفير ملفات التطبيق المرخصة في بيئة بناء خاصة، ثم شغّل اختبارات البناء والتثبيت والتشغيل والإيقاف. نجاح تجميع EXE وحده لا يثبت أن التطبيق يعمل.

## حماية الملفات
لا تضف مفاتيح أو كلمات مرور أو ملفات ترخيص خاصة أو نسخة تجارية إلى هذا المستودع العام.
