# WordPress Plugins

ضع كل إضافة داخل مجلد مستقل بهذا النمط: `Plugin-Name/`.

يفضل أن يحتوي مجلد الإضافة على:
- ملفات الإضافة الأصلية.
- `README.md`: الاسم، الإصدار، المصدر، المتطلبات وطريقة التثبيت.
- `CHANGELOG.md`: الإصلاحات والتحديثات.
- اختبارات أو ملاحظات التوافق عند توفرها.

لا تخلط ملفات إضافات مختلفة داخل المجلد نفسه.
