# WordPress Themes

ضع كل قالب داخل مجلد مستقل بهذا النمط: `Theme-Name/`.

يفضل أن يحتوي مجلد القالب على:
- ملفات القالب الأصلية.
- `README.md`: الاسم، الإصدار، المصدر، المتطلبات وطريقة التثبيت.
- `CHANGELOG.md`: الإصلاحات والتحديثات.
- `Screenshots/` عند الحاجة.

لا تضع قوالب متعددة داخل مجلد منتج واحد.
